Your phone is the remote.

Works in any mobile browser. Join like jackbox.tv: room code + name, and you're in.

Everything a party needs.

🔢

Jackbox-style joining

A 4-letter room code and a QR code on the TV. No accounts, no app store.

🔎

Search or paste

Search YouTube in the app, or paste any link: youtu.be, Shorts, Music, embeds, mobile links.

👑

Hosts stay in charge

Admins can remove, promote to next, play/pause and skip. Guests get a fair-share queue limit.

⚡

Live everywhere

Every phone and screen updates instantly over WebSockets. Add a song to an empty queue and it plays.

📜

Play history

Every song ever played, searchable and grouped by day. Tap + to bring a banger back.

🛟

Skips the duds

Videos that can't be embedded are skipped automatically, so the music never stops.

A queue board for the room.

Put /queue on a laptop or second screen: Now playing, Up next and Recently played, updating live. Read-only, so anyone can watch and nobody can meddle.

How it works

  1. 1

    Start the server

    Run it on any computer on your Wi-Fi. It prints the room code and links.

  2. 2

    Open the TV player

    Put the player page on the big screen. It waits with the room code and QR.

  3. 3

    Guests join

    Phones scan the QR or open the link, enter the code and a name.

  4. 4

    Dance 🪩

    Songs play in order. Hosts promote, skip and tidy up from their phones.

Works with the TV you have.

The player is just a web page, so if it can show a browser window, it can host the party.

🔌

HDMI

Plug a laptop into the TV and go full screen. The most reliable option.

📡

AirPlay

Mirror or extend a Mac or iPad to an Apple TV or AirPlay-capable TV.

📺

Chromecast

Cast the Chrome tab or screen to a Chromecast or Google TV.

🌐

TV browser

Smart TV with a decent browser? Open the player URL right on the TV.

Get started in a minute.

Requires Node.js 22+. A YouTube Data API key is optional (it turns on in-app search).

# grab it
git clone https://github.com/shundor/dance-party.git
cd dance-party && npm install

# set ADMIN_PIN, TV_KEY, optionally YOUTUBE_API_KEY
cp .env.example .env

# party
npm start
